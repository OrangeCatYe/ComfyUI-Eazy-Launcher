# ComfyUI_KK 专业启动器 v2.0.7 — 高保真前端复刻设计文档

> 本文是项目基准文档。所有界面重建以本文档 + `openspec/` 下的规格为准。
> 数据来源：71 张原版截图 + 反混淆后的原版前端 `bundle_READY.js`。

## 1. 项目定位

对 `KK._Portable_2.0.7.exe` 的前端界面做**像素级高保真复刻**，目标是界面外观、交互、动效与原版一致。

- **仅复刻 UI**：不含 Python/Eel 后端，所有数据为 mock（空状态优先）
- **后续可接数据**：localStorage 键名、日志输出格式、函数语义均沿用原版，接入时无需重构

## 6. 关键交互还原

### 6.1 三个「非弹窗」功能（源码实证，重要）

这三个功能**没有独立弹窗界面**，输出全部走右侧终端。

**环境比较工具** — 3 步终端向导

```
>>> 启动环境比较工具...
步骤 1/3: 请选择基准快照文件 (旧版本)...   → select_requirements_file()
步骤 2/3: 请选择目标快照文件 (新版本)...   → select_requirements_file()
步骤 3/3: 正在分析差异...                 → compare_snapshots(基准, 目标)
```
差异分 `added` / `removed` / `changed` 三组输出到终端。

**查询引用插件** — 前置校验 + 终端输出

```js
if (!库名)  return alert("提示", "请先输入要查询的库名")
if (!路径)  return alert("提示", "ComfyUI 路径未设置")
log(">>> 正在扫描引用了 [" + 库名 + "] 的插件...")
r = await find_lib_in_plugins(路径, 库名)
// 有结果
🔍 查询结果: 发现 N 个插件依赖此库:
 - 插件名
 (基于 requirements.txt 声明检测)
// 无结果
🔍 查询结果: 未发现任何插件显式依赖 [库名]。
```

**恢复快照依赖** — 唯一在页面内渲染差异的功能

点击后页面内出现差异分组区（不是弹窗）：

```js
diff = {
  remove: [], update: [], install: [],
  localWhl: [], snapshotCount: 0,
  snapshotMeta: null, currentMeta: null, versionMismatch: []
}
```

渲染 `待移除 / 待更新 / 待安装` 三个可勾选列表，底部「开始恢复」。执行时写终端：

```
>>> 开始恢复快照依赖: <path>
>>> 恢复快照依赖完成      或      >>> 恢复失败: <error>
```

### 6.2 其他已验证交互

## 8.1 交互完备性补齐（S7）

阶段 S1–S6 完成后核查发现 **64 个 `<Button>` 没有 `onClick`**，
即页面渲染完整但点了没反应。已全部补齐，按功能性质分三类处理：

**走终端日志**（会产生命令输出）：插件的安装/切换/启用/卸载、
4 个批量操作、内核的切换仓库/刷新/切换版本、
环境依赖的 pip 安装卸载与示例命令、部署目录选择与重置。

**走 Toast**（页内工具操作）：各工具页的刷新/删除/复制/开始任务、
设置页的保存配置/重置默认/网络连通测试。

**走 ConfirmModal**（不可撤销）：插件卸载、模型与作品删除、
部署环境重置。

同时补齐的还有：

- **实用工具长按拖拽排序**（此前只有注释没有实现）：
  长按 400ms 进入拖拽态，顺序持久化到 `kk_tools_hub_order`，
  读取时与注册表取交集并补齐新增项。
- **批量更新弹窗**：含截图实证的「仅显示当前有新版本的插件」
  过滤项与「立即执行 (N)」按钮。
- **首页翻转卡背面的「开始任务」**：`stopPropagation` 避免冒泡翻转。
- **收藏夹两个弹窗**：新建分类（placeholder 按截图为「例如：镜头语言」）、
  添加提示词（名称/标签/图片备注/内容 四字段）。

### 复用的基础件

- `src/lib/picker.js` —— 文件/目录选择，浏览器近似实现，

### 排查方法

按钮接线情况可用脚本扫描：对每个 `.jsx` 找 `<Button` 起始、
向下取 6 行，窗口内不含 `onClick` 即为未接线。
（窗口必须足够大，多行 JSX 的 `onClick` 常在第 5 行，
窗口太窄会误报。）
