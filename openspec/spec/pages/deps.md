# 环境依赖规格

> 依据「环境依赖.png」「环境依赖-pypi源.png」
> 三个终端协议功能见 [../terminal.md](../terminal.md)

## 区块结构（7 个）

| # | 区块 | 内容 |
|---|---|---|
| 1 | PYPI 镜像源与测速 | 下拉选源 + 应用源 + 测速 |
| 2 | 检测依赖文件 | 选择 requirements.txt + 分析/检测冲突/安装 |
| 3 | ComfyUI 环境操作 | 查看当前环境 / 查找环境冲突 / 环境比较工具 |
| 4 | 第三方库管理 | 库名（搜索 / 查询引用插件）+ 版本（安装/卸载/装 whl） |
| 5 | 终端命令行 | 启动终端 / 示例命令 |
| 6 | 环境快照备份 | 备份当前环境 / 恢复快照依赖 |
| 7 | 输出日志与结果 | 复制日志信息 / 清空日志信息 + 日志流 |

## 镜像源

5 个：阿里云、清华大学、腾讯云、华为云、官方源。
测速依次输出每个源的耗时，完成后**自动切换到最快源**，
终态输出 `>>> 测速完成!检测到最快源为:X(0.xxx秒)\n已自动切换。`

## 三个终端协议功能

| 功能 | 形态 | 说明 |
|---|---|---|
| 环境比较工具 | 纯终端 3 步向导 | **无弹窗**，任一步取消输出「操作已取消。」 |
| 查询引用插件 | 前置校验弹窗 + 终端输出 | 校验用 `window.alert`，非自定义 Modal |
| 恢复快照依赖 | 页面内差异表 + 终端日志 | **唯一**有页面内 UI 的功能 |

**反例提醒**：不要为「环境比较工具」「查询引用插件」设计自定义弹窗。
规范原文强调过，实现时 `runCompareEnv` / `runFindRefs` 必须走终端。

## 查询引用插件的校验

| 条件 | 行为 |
|---|---|
| 库名为空 | `alert('提示\n请先输入要查询的库名')` |
| ComfyUI 路径未设置 | `alert('提示\nComfyUI 路径未设置')` |

ComfyUI 路径取自 App 的 `comfyRoot`（来自统一设置层）。

## 其它按钮

| 按钮 | 行为 |
|---|---|
| 选择文件 | `pickFile('.txt')`，选中后显示文件名 |
| 安装选中 | `>>> pip install <库名>` |
| 卸载选中 | `>>> pip uninstall -y <库名>` |
| 安装轮子.whl | `pickFile('.whl')` 后输出 `>>> pip install <文件>` |
| 示例命令 | 输出 3 条常用 pip 命令 |

## 日志区

页面内日志区与底部终端**共享同一份 logs**，
「复制日志信息」写入剪贴板，「清空日志信息」调用 `clear()`。

## 动作出口

全部通过 `onAction(name, payload)` 回调到 App 的 `handleDepsAction`。
三个协议功能在该函数开头被分流到独立实现，
其余走 `map` 表的日志文案映射。
