# 实用工具规格

> 依据「实用工具.png」+ 各工具页补充截图

## 工具网格

卡片网格 `sm:grid-cols-2 xl:grid-cols-3`，每张卡含：
图标（渐变底）/ 标题 / 描述 / 悬停显示「点击开始使用 →」。

`kind: 'action'` 的卡片右上角显示「外链」徽标。

## 顺序持久化（长按拖拽排序）

长按 **400ms** 进入拖拽态：

- 被拖卡片：`opacity-50 scale-[0.98]` + 靛蓝描边
- 悬停的目标卡片：`ring-2 ring-indigo-400/40`
- 松手落位：把拖拽项插入到目标位置

顺序存 `localStorage` 键 `kk_tools_hub_order`（沿用原版键名），
只存 id 数组。**读取时与注册表做交集 +
补齐新增**，即：先按保存顺序还原已存在的工具，
再把注册表里新增的追加到末尾。
这样后续往注册表加工具不会被旧的顺序数据吞掉。

用 `didDrag` 标记位避免拖拽结束的那次 click 误触发打开工具。
底部有一行提示文案「长按卡片可拖拽排序，顺序会自动保存。」

## 各工具页要点

### 模型管理
左侧模型目录（checkpoints / diffusion_models / loras / 其它目录），
右侧 8 个快捷筛选 + 搜索 + 排序 + 全选。
顶部：刷新列表（旋转图标 + 「读取中...」）/ 设为常用 / 删除已选。
删除走 `ConfirmModal`；未勾选时提示「请先勾选要删除的模型」。
空态文案：`当前条件下没有找到模型文件。`

### 检测重复模型
按文件名 / 哈希值两种扫描方式，5 种格式过滤
（`.safetensors` `.ckpt` `.bin` `.pt` `.gguf`）+ 高级选项（扫描目录）。
开始检测：校验至少选一种格式，扫描中禁用按钮并显示旋转图标，
可「取消检测」。结果区底部「移动到回收站」。

### 识图反推提示词
拖拽上传区（支持点击选择 + 拖放）+ 结果区。
上传后显示文件名，未上传点「开始反推」会提示。
「复制」把结果写入剪贴板，无结果时提示。
「管理模型」提示远程模型接口按视觉模型排序、可勾选「支持视觉」。

### 工作流管家
工作流列表 + 启动分析 + 未识别节点明细 + 临时禁用插件列表。
刷新列表、全选/取消全选、启动所选（未选择时提示）。
统计数字与列表联动。

### 提示词收藏夹
分类卡（闪念胶囊 / 创作提示词 / 人物设定模板）+ 两个弹窗。
- 新建收藏夹：名称（placeholder **例如：镜头语言**）+ 上级分类，空名提示
- 添加提示词：名称 / 标签 / 图片备注 / 提示词内容 四字段，空名提示
新建的分类追加到列表并更新「分类」计数；闪念胶囊侧栏走动态数据。

### 提示词润色
10 个目标模型卡（数据见 `src/config/tools.js` 的 `POLISH_MODELS`）。
「生成专业提示词」校验想法描述非空，输出按目标模型 + 规则拼装，
结果区 `whitespace-pre-wrap` 保留换行，「复制」写入剪贴板。

### 音视频工具
3 个 Tab：提取音频 / 消除原声 / 裁剪音频，附使用说明 3 条。
选择文件后显示文件名，执行按钮校验已选文件，
处理中禁用并显示「处理中...」，完成后 Toast 提示已保存。

### 自动关机任务
3 类：定时关机 / GPU 空闲 / ComfyUI 空闲。
每类卡片底部「开始任务」，点击后变「取消任务」且状态显示「运行中」。

### 我的作品
类型筛选（全部 / 图片 / 视频）+ 排序（最新 / 最早 / 体积）。
顶部：上一级 / 删除已选(N) / 刷新。删除走 `ConfirmModal`，
N 与勾选联动，未勾选时提示。

### 关于作者
5 个 Tab：推荐插件 / 推荐工具 / 资源网站 / 软件声明 / 作者信息。
仅「推荐插件」有真实数据（5 个插件及仓库地址），其余为空态。
「访问」打开外链，`noopener,noreferrer`；
「快捷安装」Toast 提示已加入安装队列。
