# 插件管理规格

> 依据「插件管理.png」「插件管理-安装新插件.png」「插件管理「历史」.png」

## 结构

1. **工具栏**：`N 个已安装` + 「+ 安装新插件」
2. **开关区**：自动安装依赖 / 放心装（右侧批量操作 4 个）
3. **搜索框**：搜索插件名称、地址
4. **插件卡片列表**

## 开关

| 开关 | 状态托管 |
|---|---|
| 自动安装依赖 | App 的 `autoInstall` |
| 放心装 | App 的 `safeMode` |

与内核管理页的「自动安装依赖」**共享同一状态**。

## 批量操作

批量导出、批量更新、批量开关、批量卸载（最后一个为 `variant="danger"`）。

## 插件卡片字段

名称 / 仓库地址 / 已启用徽标 / 分支 / GIT 版本 / 更新时间。
行内操作：最新、历史、启用(禁用)、卸载。

## 弹窗（3 个）

| 弹窗 | 触发 | 内容 |
|---|---|---|
| 安装新插件 | 工具栏按钮 | 仓库地址输入 + 选择本地插件目录 |
| 历史版本 | 卡片「历史」 | 提交版本列表（空态）+ 切换到指定版本 |
| 切换版本确认 | 历史版本内切换 | `ConfirmModal`，取消 / 确认 |

## 空态

未搜索：`暂无已安装插件`；搜索无结果：`未找到匹配的插件`。
