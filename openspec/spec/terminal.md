# 终端输出协议

> **本文件是项目最重要的契约之一。**
>
> 源码实证：`环境比较工具` / `查询引用插件` / `恢复快照依赖` 三个功能
> **没有独立弹窗界面**，全部通过终端输出。`恢复快照依赖` 是唯一在页面内渲染差异表的功能。
>
> 反例提醒：不要为前两个功能设计弹窗。

## 1. 日志行前缀规范

从源码提取的前缀语义，终端按前缀着色：

| 前缀 | 语义 | 渲染色 |
|---|---|---|
| `>>> ` | 命令回显与阶段提示 | accent + 加粗 |
| `\n>>> ` | 新任务起始（前空行） | accent + 加粗 |
| `🔍 ` | 扫描类结果 | info |
| `📦 ` | 依赖包条目 | text-main + 加粗 |
| ` - ` | 列表项 | text-sub + 缩进 |
| 含「失败」「错误」 | 异常 | danger |
| 含「完成」「成功」 | 成功 | success |
| 其他 | 普通输出 | text-main @ 80% |

## 2. 环境比较工具

**触发**：环境依赖页 → 环境比较工具按钮
**形态**：3 步终端向导，全程无弹窗

```
>>> 启动环境比较工具...
步骤 1/3: 请选择基准快照文件 (旧版本)...
基准文件: <path>
步骤 2/3: 请选择目标快照文件 (新版本)...
目标文件: <path>
步骤 3/3: 正在分析差异...
```

**后端调用序列**

| 步骤 | 调用 |
|---|---|
| 1 | `select_requirements_file()` |
| 2 | `select_requirements_file()` |
| 3 | `compare_snapshots(基准, 目标)` |

**取消语义**：任一步返回空 → 输出 `操作已取消。`

**成功输出**：差异分三组 —— `added` / `removed` / `changed`

## 3. 查询引用插件

**触发**：环境依赖页 → 查询引用插件按钮
**形态**：前置校验（唯一弹窗）+ 终端输出

**校验规则**

| 条件 | 弹窗 | 文案 |
|---|---|---|
| 库名为空 | `alert` | `提示 / 请先输入要查询的库名` |
| ComfyUI 路径未设置 | `alert` | `提示 / ComfyUI 路径未设置` |

**执行输出**

```
>>> 正在扫描引用了 [<库名>] 的插件...
```

**有结果**

```
🔍 查询结果: 发现 <N> 个插件依赖此库:
 - <插件名>
 - <插件名>
(基于 requirements.txt 声明检测)
```

**无结果**

```
🔍 查询结果: 未发现任何插件显式依赖 [<库名>]。
```

**异常**：`查询失败: <error>`

**后端调用**：`find_lib_in_plugins(comfyuiPath, 库名)`

## 4. 恢复快照依赖

**触发**：环境依赖页 → 恢复快照依赖按钮
**形态**：页面内差异表 → 勾选 → 执行 → 终端日志（**唯一有页面内 UI 的功能**）

### 4.1 页面内差异结构

```js
diff = {
  remove: [],          // 待移除
  update: [],          // 待更新
  install: [],         // 待安装
  localWhl: [],        // 本地 whl
  snapshotCount: 0,
  snapshotMeta: null,
  currentMeta: null,
  versionMismatch: []
}
```

渲染 `待移除 / 待更新 / 待安装` 三个分组，每项带 checkbox，默认全选。
底部按钮「开始恢复」，显示已选数量。

### 4.2 预览

后端调用：`preview_restore_snapshot(pythonPath, snapshotPath)`
记录动作标记：`lastAction = "恢复快照依赖-预览"`

### 4.3 执行

```
>>> 开始恢复快照依赖: <path>
>>> 恢复快照依赖完成
```

失败：

```
>>> 恢复失败: <error>
```

**后端调用**：`restore_env_snapshot(pythonPath, snapshotPath, selections)`
其中 `selections` 形如：

```js
{
  remove: ["pkgA", "pkgB"],
  update: ["pkgC"],
  install: ["pkgD"]
}
```

记录动作标记：`lastAction = "恢复快照依赖-执行"`

## 6. 日志写入器 API

```js
const { push, pushLines, clear } = createLogger(setLogs)

push('>>> 启动...')         // 单行，支持含 \n 的字符串自动展开
pushLines(['a', 'b'])       // 多行
clear()                     // 清空
```

原版语义：用 `_0x1021a9(text)` 单行写入，复杂结果用 `\n` 拼接后一次性输出。
